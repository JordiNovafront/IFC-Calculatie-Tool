Veel-op-veel

Eén element hangt aan meerdere calculatieregels, en één calculatieregel telt veel elementen op. Klopt dit met hoe wij calculeren?

Eén element → meerdere regels
Betonwand→ betonmortel (m³) → bekisting (m²)→ wapening (kg, via kg/m³) → schilderwerk (m²)
Eén regel ← meerdere elementen
Betonmortel← betonwand 8,55 m³ ← betonvloer 20,00 m³← betonkolom 0,48 m³ = 29,03 m³
